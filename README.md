# sportsnet

This project contains two things:

* A framework to train neural networks built on top 
  of [deeplearning4j](https://deeplearning4j.org/).
    
* An implementation of the framework for multiple sports:
  - NCAA Basketball
  - NBA
  - NHL
  - NFL
  
Other sports are coming:
* MLB (Fall 2021)

SportsNeurd (A name I'm toying with) is geared towards tournaments,
or playoffs. It uses regular season data to train networks that can
then be run to predict tournament outcomes: 
  - March Madness (NCAA BB)
  - Stanley Cup (NHL)
  - NBA Playoffs
  - Superbowl (NFL)
